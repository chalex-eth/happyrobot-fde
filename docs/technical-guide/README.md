# Technical submission guide

- [Technical submission PDF](technical-submission.pdf): eight A4 pages for assessors.
- [Editable HTML](index.html): self-contained styles and vector diagrams.
- [Evaluation snapshot](evaluation-snapshot.json): sanitized selected local results for 22 Custom Tests and eight adversarial cases.

The guide describes source commit `ba4079a` and was prepared on 8 September 2026.
It does not certify the live platform configuration or rerun native evaluations.
The snapshot selects the most recently modified local result artifact per case;
file modification time is not execution time. Individual artifacts omit version
IDs, so exact run-to-version provenance requires platform readback.

Keep companion files together. PDF companion links are relative; repository
source links point to the reviewed commit and require repository access.

To export after editing, print the HTML as A4 portrait at 100% with background
graphics enabled and browser headers/footers disabled. Verify eight pages and
review the rendered output. Avoid exporting machine-specific file links.

Before submitting, supply the exact workflow link, private repository access,
prospect summary email and walkthrough video. Requirements gaps are documented explicitly. Historical results remain in the
companion snapshot but are not presented in this edition of the guide.
