# Client operations guide

The client-ready export is [operations-guide.pdf](operations-guide.pdf).

Open `index.html` directly in a browser. It is a self-contained, seven-page
document: styles, illustrations and interface captures are embedded. No build,
server, account or network connection is required to read it.

For PDF export, select **Print / Save PDF**, choose **A4 portrait**, use **100%**
scale, enable **background graphics**, and disable browser **headers and footers**.
The document supplies its own page margins and numbering.

Content and interface labels reflect the September 2026 demo. Captured figures
are examples, not production performance. The workspace link comes from the
repository README. Add the walkthrough link when the final video is available.

Keep the simulation explanations beside the approval and follow-up instructions
when editing. The guide does not contain operator credentials.
