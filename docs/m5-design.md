# M5 surface brief
Mode: Operate. Extend the existing light, ink/teal interface in the current app.
The approved composition is a compact call banner above an operator lane map and
calls/review table. Preserve visible hierarchy, spacious groups and restrained
borders. The map is a geographic visualization with attributed data; no decorative
truck movement. Selected lanes coordinate with the load list. Operator reasons
and review actions must be readable before expanding full call details. Desktop
uses map/list columns; mobile stacks them. Call controls and OTP remain adjacent.

Network map: display all returned US lanes by default. Equipment and availability
filters narrow the same inventory snapshot. Keep dense city labels to the selected
lane, with readable equipment/status details beneath the map.

City markers reveal city/state names on hover or keyboard focus. Clicking a marker
selects the same city/state value as the city dropdown and filters both ends of each
lane. The selected city stays labeled; All cities restores the network.

City hover highlights connected routes and reduces other route opacity to 18%
without filtering them. Clicking the selected marker again clears the city filter.
